🎯 QUICK START COMMANDS
═══════════════════════════════════════════════════════════════════════════════

Install Dependencies (one-time):
  cd backend && php ../composer.phar install
  cd ../frontend && npm install

Start Development Servers:

  Terminal 1 - Backend:
    cd backend && php -S localhost:8001 -t public

  Terminal 2 - Frontend:
    cd frontend && npm run dev

  Terminal 3 (Optional) - Monitor Redis:
    redis-cli -h localhost -p 6379 -a '<USE_ENV>' MONITOR

Test Connections:

  PostgreSQL:
    psql -h localhost -U blog_admin -d blog_platform
    Password: <USE_ENV>

  Redis:
    redis-cli -h localhost -p 6379 -a '<USE_ENV>' PING

  Backend Health:
    curl http://localhost:8001/api/v1/health

  Frontend:
    Open browser to http://localhost:3000
