================================================================================
⚙️ COMO USAR AGORA
================================================================================

1. Iniciar Backend:
   $ cd backend
   $ php -S localhost:8000 -t public

2. Iniciar Frontend Dev:
   $ cd frontend
   $ npm run dev

3. Testar API:
   $ curl http://localhost:8000/api/v1/posts

4. Ver Documentação:
   - Índice geral: docs/INDEX.md
   - Próximos passos: docs/guides/NEXT_STEPS.md
   - Plano completo: docs/4-PLANO_DE_EXECUCAO.md

5. Listar Posts via CLI:
   $ curl "http://localhost:8000/api/v1/posts?status=published&language=pt" | python3 -m json.tool
