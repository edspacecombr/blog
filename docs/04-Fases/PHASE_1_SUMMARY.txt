================================================================================
COMO USAR A API
================================================================================

1. Listar posts publicados em português:
   GET /api/v1/posts?status=published&language=pt&page=1

2. Obter post específico:
   GET /api/v1/posts/18?language=pt

3. Criar novo post:
   POST /api/v1/posts
   {
     "title": "Novo Post",
     "content": "Conteúdo do post",
     "author_id": 1,
     "language": "pt",
     "status": "draft"
   }

4. Atualizar post:
   PATCH /api/v1/posts/18
   {
     "title": "Título Atualizado",
     "status": "published"
   }

5. Deletar post:
   DELETE /api/v1/posts/18
