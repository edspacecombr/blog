EXEMPLOS DE USO
================================================================================

UPLOAD DE MÍDIA:
  POST http://localhost:8000/api/v1/media
  -F "file=@/path/to/image.png"

  Resposta:
  {
    "data": {
      "id": 1,
      "filename": "uuid.png",
      "url": "/storage/uploads/2026/02/uuid.png",
      "webp_url": "/storage/uploads/2026/02/uuid.webp",
      "avif_url": "/storage/uploads/2026/02/uuid.avif",
      "mime_type": "image/png",
      "size": 12345,
      "alt_text": {},
      "created_at": "2026-02-24T14:48:35+00:00"
    }
  }

ATUALIZAR ALT TEXT:
  PATCH http://localhost:8000/api/v1/media/1/alt-text
  Content-Type: application/json

  {
    "pt": "Imagem de teste",
    "en": "Test image"
  }

LISTAR MÍDIAS:
  GET http://localhost:8000/api/v1/media?page=1&per_page=15

CRIAR POST COM CONTEÚDO SANITIZADO:
  POST http://localhost:8000/api/v1/posts
  Content-Type: application/json

  {
    "title": "Meu Post",
    "content": "<p>Conteúdo seguro</p>",
    "author_id": 1,
    "language": "pt"
  }
