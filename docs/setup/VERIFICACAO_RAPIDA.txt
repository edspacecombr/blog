🆘 SE ALGO ESTÁ FALTANDO

Database não conecta?
  → Verifique se PostgreSQL está rodando em Docker (WSL2)
  → docker ps | grep postgres

Redis não conecta?
  → Verifique se Redis está rodando em Docker (WSL2)
  → docker ps | grep redis

Backend não inicia?
  → Porta 8001 pode estar em uso: lsof -i :8001
  → Use porta diferente: php -S localhost:8002 -t public

Frontend não inicia?
  → Porta 3000 pode estar em uso: lsof -i :3000
  → Limpe cache: rm -rf frontend/.next
  → Reinstale: cd frontend && npm install
