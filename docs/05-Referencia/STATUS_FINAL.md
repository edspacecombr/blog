│          Developer Push to main/develop         │

                 ↓
┌─────────────────────────────────────────────────┐
│          GitHub Actions Triggered               │
└────────────────┬────────────────────────────────┘
                 ↓
    ┌────────────┼────────────┐
    ↓            ↓            ↓
┌──────────┐ ┌──────────┐ ┌────────────┐
│ Backend  │ │ Frontend │ │ Security   │
│ Tests    │ │ Tests    │ │ Scan       │
│(2min)    │ │(2min)    │ │(1min)      │

     └────────┬───┘────────────┘
              ↓
    ┌─────────────────────┐
    │ Build Verification  │
    │ (npm build)         │
    └────────┬────────────┘
             ↓
    ┌─────────────────────┐
    │ Deploy Decision     │
    │ (if main branch)    │
    └────────┬────────────┘
             ↓
    ┌─────────────────────┐
    │ Deploy Backend      │
    │ Deploy Frontend     │
    │ Notify Slack        │
    └─────────────────────┘
