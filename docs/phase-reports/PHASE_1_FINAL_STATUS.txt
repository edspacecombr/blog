Pattern Implementado:
  Request → Controller → Model → Database
          ↓
     Resource ← Formatting ← Data
          ↓
     JSON Response

Validações:
  - Campo obrigatório → 422 Unprocessable Entity
  - Recurso não encontrado → 404 Not Found
  - Foreign key violado → 500 Internal Server Error
  - Success → 200 OK / 201 Created
  - Paginação → Links HATEOAS + Meta

COMO EXECUTAR
================================================================================

1. Iniciar Backend:
   cd backend && php -S localhost:8001 -t public

2. Testar Endpoints:
   curl http://localhost:8001/api/v1/posts

3. Criar um Post:
   curl -X POST http://localhost:8001/api/v1/posts \
     -H "Content-Type: application/json" \
     -d '{"title":"Test","content":"...","language":"en"}'

4. Listar com Paginação:
   curl "http://localhost:8001/api/v1/posts?page=1&per_page=5"

5. Monitor Redis (opcional):
   redis-cli -h localhost -p 6379 -a 'd4m@!62R' MONITOR
