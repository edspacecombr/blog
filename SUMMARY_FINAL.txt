COMO COMEÇAR
================================================================================

1. LEIA A DOCUMENTAÇÃO:
   → docs/INDEX.md (índice completo)
   → docs/03-Guias/LEIA_PRIMEIRO.md (guia inicial)

2. SETUP LOCAL - BACKEND:
   cd backend
   composer install
   cp .env.example .env
   php migrate.php
   php seed.php
   php -S localhost:8000 -t public

3. SETUP LOCAL - FRONTEND:
   cd frontend
   npm install
   echo "NEXT_PUBLIC_API_URL=http://localhost:8000/api/v1" > .env.local
   npm run dev

4. ACESSO:
   Admin: http://localhost:3000/admin
   Frontend: http://localhost:3000
   API: http://localhost:8000/api/v1

5. DEPLOY:
   Seguir: docs/06-deployment/DOCUMENTACAO_TECNICA_COMPLETA.md
