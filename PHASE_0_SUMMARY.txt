🚀 GETTING STARTED

Installation (PostgreSQL + Redis):
  Prerequisites:
    1. Install PostgreSQL 13+
    2. Install Redis 6+
    3. Install PHP 8.1+ with pdo_pgsql + redis extensions
  
  Setup:
  1. chmod +x setup.sh
  2. ./setup.sh (installs PHP deps)
  3. Create PostgreSQL database (see docs/POSTGRESQL_REDIS_SETUP.md)
  4. Configure .env with PostgreSQL + Redis credentials
  
  OR Manual:
  1. cd backend && composer install
  2. cd ../frontend && npm install

Start Development (PostgreSQL + Redis):
  Terminal 1 (Redis):
    redis-server
    
  Terminal 2 (Backend):
    cd backend
    php -S localhost:8000 -t public
    
  Terminal 3 (Frontend):
    cd frontend
    npm run dev

Access:
  • Frontend: http://localhost:3000
  • Backend: http://localhost:8000
  • API Health: http://localhost:8000/api/v1/health
  • Redis Monitor: redis-cli MONITOR
