🚀 GETTING STARTED

Installation:
  1. chmod +x setup.sh
  2. ./setup.sh
  
  OR Manual:
  1. cd backend && composer install
  2. cd ../frontend && npm install

Start Development:
  Terminal 1 (Backend):
    cd backend
    php -S localhost:8000 -t public
    
  Terminal 2 (Frontend):
    cd frontend
    npm run dev

Access:
  • Frontend: http://localhost:3000
  • Backend: http://localhost:8000
  • API Health: http://localhost:8000/api/v1/health
